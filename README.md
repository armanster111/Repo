# FIFA World Cup Live Analytics

A browser dashboard for FIFA World Cup games that shows live scores, match status,
possession, pressure, shot accuracy, cards, corners, and key events.

The app runs a small Node server that proxies ESPN's public FIFA World Cup data so
the browser can refresh without CORS issues.

## Run

```bash
npm start
```

Open http://localhost:3000 in a browser.

## Test

```bash
npm test
```
