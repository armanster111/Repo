# Repo

Misc projects live on feature branches.

The **Muse** music visualizer moved to [github.com/armanster111/muse](https://github.com/armanster111/muse).

To publish Muse after creating that repository:

```bash
bash scripts/push-muse-repo.sh
```

Or push the export branch directly:

```bash
git push https://github.com/armanster111/muse.git muse-export:main
```
