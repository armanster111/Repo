# Music Visualizer Ultra

The most advanced standalone Windows music visualizer — **60 FPS**, **FFT spectrum analysis**, **22 visual modes**, **6 UI styles**, cinema showcase, OBS overlay, library, lyrics, DJ mode, and LAN remote control. One `.exe`, no install.

## Download

1. **[MusicVisualizerPro-Windows.zip](https://github.com/armanster111/Repo/raw/cursor/music-visualizer-exe-7b99/dist/MusicVisualizerPro-Windows.zip)**
2. Extract → double-click **`MusicVisualizerPro.exe`**

Direct EXE: https://github.com/armanster111/Repo/raw/cursor/music-visualizer-exe-7b99/dist/MusicVisualizerPro.exe

## Highlights

| Feature | Details |
|--------|---------|
| **60 FPS** | Double-buffered rendering |
| **FFT spectrum** | MP3, WAV, FLAC, OGG + desktop audio |
| **22 visual modes** | Classic through Fluid, Galaxy, Chromatic shaders |
| **6 UI styles** | Classic, Minimal, Compact, Glass, Studio, Light (**F8**) |
| **Cinema mode** | **F9** — fullscreen auto-cycling showcase |
| **Export** | **C** PNG snapshot · **2** GIF · **\*** AVI video |
| **OBS overlay** | **1** — draggable transparent window |
| **Library** | Artist/album views, scrollable playlist |
| **Remote** | http://127.0.0.1:8765 |

Press **F1** in-app for the full shortcut list.

## Quick controls

| Key | Action |
|-----|--------|
| **F1** | Keyboard shortcuts overlay |
| **F8** | Cycle UI style |
| **F9** | Cinema showcase |
| **V** | Cycle visualizers |
| **G** | Cycle color theme |
| **C** | PNG snapshot to Desktop |
| **2** / **\*** | Record GIF / AVI video |
| **1** | OBS overlay |
| **3** | Settings panel |
| **Space** | Play/pause |

## For streamers

1. Press **F9** for cinema mode
2. Press **1** for OBS overlay
3. Add Window Capture in OBS → "Music Visualizer Overlay"
